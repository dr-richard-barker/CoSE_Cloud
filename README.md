# COSE Cloud

The hub / front door for the **COSE** space-biology project family.

**→ Hub: https://dr-richard-barker.github.io/CoSE_Cloud/Hub/**

The hub is a directory of every project, generated from the shared registry
(`sites.js`) hosted with the CoSE theme kit at
`https://dr-richard-barker.github.io/Plant_response_to_radiation/cose/`, so it
stays in sync automatically as projects are added.
